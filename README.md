AurumSpark — швейцарська екосистема для організації преміальних дитячих свят, інтерактивних шоу та міжнародних фестивалів.
Платформа автоматизує логістику магічних івентів, менеджмент аніматорів та артистів, гарантуючи найвищий стандарт безпеки.
• Регіон: Швейцарія (IPI) / Глобально (WIPO Madrid, 41 клас ТМ).
• Стек: Next.js, Node.js, PostgreSQL.
