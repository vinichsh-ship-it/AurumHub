# AurumHub
AurumHub — швейцарська екосистема для міжнародної організації дитячих свят, масштабних фестивалів та шоу. Центральний хаб поєднує автоматизацію логістики, анімацію, менеджмент артистів та безпеку дитячих івентів. • Регіон: Швейцарія (IPI) з розширенням через WIPO Madrid (41 клас ТМ). • Стек: Next.js, Node.js, PostgreSQL
